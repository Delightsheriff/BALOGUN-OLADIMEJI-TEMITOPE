Algorithm & Implementation

CART Decision Tree (Gini index), implemented via Python scikit-learn. Settings: max_depth=4, min_samples_leaf=4, max_features=3 (full-term model) and balanced class weights, to keep the tree small and readable and to limit overfitting.
